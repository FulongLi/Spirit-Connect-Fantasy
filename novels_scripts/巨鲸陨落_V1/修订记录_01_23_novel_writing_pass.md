# 《巨鲸陨落》01-23 章 novel-writing 修订记录

本轮修订依据项目内 `.codex/skills/novel-writing` 的 Revision / Scene and Structure / Style Fidelity 规则执行。

## 修订范围

- 中文正文：`zh_md/01` 至 `zh_md/23`
- 中文阅读页：对应 `zh_html/01` 至 `zh_html/23`
- 英文版：本轮未做情节同步改写，因为中文调整主要为等义句式和叙述方式优化。

## 主要发现与处理

- Location: 01-08 章，多处开篇感官与逃亡段落
  Problem type: style fidelity / pacing
  What happens now: 一些关键身体感受通过“不是……而是……”直接解释。
  Why it fails: 这种句式会把梦境战场的沉浸感短暂拉回说明文语气。
  Revision direction: 改为身体感、动作、观察顺序来完成判断，例如把“那不是快乐。那是……”改为“那笑声里没有快乐。活下来的人正在……”
  Should this become a project rule?: yes，已写入 `AGENTS.md`。

- Location: 10-13 章，鳞裔族、节肢族、渊民族、震翼族背景初露段
  Problem type: scene structure / exposition
  What happens now: 部分设定句把文明特征讲得过直。
  Why it fails: 读者应该先从遗迹、声音、动作和误读中理解文明，而不是先收到百科式结论。
  Revision direction: 保留设定信息，但把“这是 X，不是 Y”式判断改成墙壁、舱体、频率、水声等可见可感元素。
  Should this become a project rule?: yes。

- Location: 17-23 章，地球方案与巨鲸文明揭示段
  Problem type: reveal pacing
  What happens now: 几处揭示语句过于直接，容易削弱“查理逐步明白”的过程。
  Why it fails: 这部分承担全书世界观第一次大开门，叙述如果太像定义，会减少震撼。
  Revision direction: 减少定义感，把揭示改成“查理意识到”“画面呈现”“讯息压入意识”等渐进形式。
  Should this become a project rule?: yes。
