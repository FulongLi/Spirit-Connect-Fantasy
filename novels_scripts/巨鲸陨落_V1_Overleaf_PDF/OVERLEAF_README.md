# Giant Whale Fall V1 Overleaf Package

This package contains the Chinese reading draft of `巨鲸陨落_V1`.

Use these Overleaf settings:

- Main file: `main.tex`
- Compiler: XeLaTeX
- Encoding: UTF-8

Notes:

- All internal file names are ASCII to avoid path encoding problems on Overleaf.
- The Chinese chapter text remains UTF-8 inside the `.tex` files.
- The source prose was imported from `巨鲸陨落_V1/zh_md`.
- `00_书名页与写作说明.md` was not included because it is a planning/framework note rather than novel body text.
