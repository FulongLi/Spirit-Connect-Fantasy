# 巨鲸陨落 V1 Overleaf 工程说明

这个文件夹是《巨鲸陨落_V1》的独立 Overleaf / LaTeX 阅读稿工程，不改动原始模板文件夹。

- 正文来源：`../巨鲸陨落_V1/zh_md/`
- 已导入章节：第 1 章至第 49 章
- 未导入正文：`00_书名页与写作说明.md`，因为它是写作框架和说明，不是小说正文
- LaTeX 主文件：`main.tex`
- 章节入口：`chapters/chapters-list.tex`
- 章节文件：`chapters/01-chapter-01.tex` 到 `chapters/49-chapter-49.tex`
- 本地编译 PDF：`build/main.pdf`
- 便于阅读的命名 PDF：`巨鲸陨落_V1_全文阅读稿.pdf`
- Overleaf 上传包：`giant_whale_fall_v1_overleaf_ascii.zip`

Overleaf 中建议设置：

- Compiler：XeLaTeX
- 文件编码：UTF-8
- 主文件：`main.tex`

压缩包内部文件名全部使用 ASCII，避免 Overleaf 对中文路径或中文文件名处理不稳定。
