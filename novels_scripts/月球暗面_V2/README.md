# 月球暗面_V2

这是《灵接科技》第一本《月球暗面》的 V2 工程目录。

- `md/`：当前 V2 中文正文母本，延续 V1 原始章节，不作为本轮框架重拆对象。
- `html/`：当前 V2 中文正文阅读 HTML。
- `zh_md/`：按《巨鲸陨落_V1》格式拆分后的中文结构正文稿，已填入当前 V2 母本对应正文。
- `zh_html/`：中文结构正文稿阅读 HTML。
- `en_md/`：英文对应章节正文翻译稿，文件名与 `zh_md/` 保持一致。
- `en_html/`：英文章节正文阅读 HTML。
- `index.html`：中文结构正文稿阅读目录。
- `index_EN.html`：英文正文阅读目录。
- `V2重启修订框架_CN.md` / `V2_restart_revision_framework_EN.md`：本轮 V2 的保护规则与修订路线。

当前原则：

- 第一章《月暗之旅》和第二章《新世纪》是作者原声锚点，原则上不做内容重写。
- `zh_md/zh_html` 现在是供阅读和讨论的结构正文稿，不替代 `md/` 母本。
- `en_md/en_html` 已同步为英文正文翻译阅读层。
