《月球暗面》V2 重启修订框架

整理日期：2026-06-10 当前原则：V2 以 V1 原版为母本，不再沿用此前误改方向。第一章、第二章是作者原声锚点，原则上不做内容重写。

一、这次重启要纠正什么

此前 V2 的方向偏成了“重新写一本更规整的小说”。这不符合当前目标。

现在的 V2 应该是：

  • 保留 V1 原有故事线、章节顺序和第一人称叙述气质。
  • 第一章《月暗之旅》、第二章《新世纪》尽量不改正文内容。
  • 后面章节只在确实影响阅读、人物动机、信息释放和节奏的地方做结构性修订。
  • 使用 novel-writing skill 的规则来判断场景功能、人物出场、信息可得性和风格保真。
  • Markdown 作为协作修订文件，HTML 作为阅读文件。

此前误改版本已不作为当前 V2 来源。当前 月球暗面_V2 已重置为 V1 母本。

二、V2 的核心修订目标

V2 不是把原稿“写漂亮”，而是让原稿中已经存在的命运线更自然地显形。

主线应当仍然是：

吉姆在第二次数字矫正中误入月球暗面，发现月球暗面并不是普通梦境或虚拟异常，而是通向泰拉撒记录和更高意识结构的入口。安娜与查理被困，卢恩博士、斯皮尔先生和旧时代科研者各自掌握不完整的真相。吉姆最终选择以死在月球为代价，进入真实的月暗系统，救出朋友，也打开后续系列的第一道门。

需要加强的不是“作者解释更多”，而是：

  • 让每一次信息出现都有场景压力。
  • 让每一个决定都来自人物已经经历过的事情。
  • 让“命中注定”成为累积结果，而不是叙述者直接推着角色走。
  • 让读者先在人物身上感到危险、怀疑、牵挂，再接受大设定。

三、第一章和第二章的保护规则

第一章《月暗之旅》

保护级别：最高。

这一章是全书最重要的原声样本。它的价值不只在情节，而在那种“半梦半科考、半恐惧半好奇”的叙述状态：

  • 吉姆一边害怕，一边忍不住观察。
  • 宏大景象通过个人身体感受进入，比如黑水、石门、荒漠、稻田、时间片、黑白空间和蓝黑色球体。
  • 叙述里有不确定、猜测、突然的幽默和自我怀疑。
  • 很多设定不是被解释出来，而是像梦境残片一样被吉姆碰到。

V2 允许做：

  • 明显错字、标点、段落断句修正。
  • 个别过长段落的轻微分段。
  • 人名或术语与系列设定对齐时的最低限度处理。

V2 不应做：

  • 改写成第三人称或全知视角。
  • 把梦境式探索压缩成清晰任务流程。
  • 删除吉姆的犹豫、困惑、身体反应和旁枝想法。
  • 提前解释艾拉、泰拉撒、时间井或月球系统的真实性质。

第二章《新世纪》

保护级别：最高。

这一章是世界观进入现实社会的原声样本。它的重点不是写一个完美科幻社会说明书，而是让吉姆用自己的方式解释他生活的时代：

  • 双生模式。
  • 数字矫正。
  • 灵接科技。
  • 《另一个世界》。
  • 十八岁事故。
  • 数字吉姆的第一次正面威胁。

V2 允许做：

  • 人名统一。
  • 个别转述顺序微调，避免读者暂时迷路。
  • 标点、错字、长段落拆分。

V2 不应做：

  • 大幅删掉吉姆解释世界的口吻。
  • 把社会设定改成百科条目。
  • 在第二章提前抹平数字吉姆的暧昧性。
  • 把卢恩博士写成已经知道全部真相的人。

六、重点问题与修订方向

1. 地球文明历史讲得太泛

现状：第三章和第五章中，生命起源、人类文明、神话、罗斯威尔、黑潮、意识与灵魂等信息连续出现，容易像讲座。

修订方向：

  • 把一大段历史拆成几个“触发点”：月暗记录中出现异常图像、专家提出互相矛盾的解释、旧档案揭示一部分、卢恩或斯皮尔隐瞒另一部分。
  • 每一段历史都服务一个眼前问题：安娜和查理为什么回不来？月球为什么是关键？吉姆为什么是钥匙？灵接科技为什么不能公开？
  • 保留“神话是早期人类对高阶科技的有限描述”这一核心想法，但减少抽象铺陈。

2. 主角团进入《另一个世界》的段落不够有力

现状：第四章有三人第一次游戏经历，但后面容易转成项目介绍。

修订方向：

  • 让游戏段落承担人物功能：吉姆负责多管闲事和异常直觉，安娜负责读规则，查理负责普通人的反应和情绪温度。
  • 隐藏任务不要只是奇遇，要预示三个人后续命运：救人、识别规则、进入非人类尺度历史。
  • 技术说明压缩成角色互动、任务反馈或内部文件片段，不让叙事从小说切换成产品说明。

3. 吉姆独自去月球的过程太草率

现状：第六、七章已经有正确方向，但从发现方法到赴月死亡，中间的心理、伦理和现实操作可以更扎实。

修订方向：

  • 先让吉姆尝试别的办法失败：继续呼叫、让卢恩检查、尝试数字路径、询问老一代。
  • 让“死在月球”不是一个突然答案，而是肖恩理论、艾拉暗示、月暗经验和安娜/查理困境共同逼出来的结论。
  • 卢恩博士不能只是协助者，也要成为阻止者、见证者和最终不得不放手的人。
  • 吉姆的决定要同时包含恐惧、责任、冲动和对朋友的具体记忆。

4. 大设定与人物命运的比例

现状：设定很有想象力，但有些段落让人物暂时退场。

修订方向：

  • 每个设定段落后都要回答：它让谁改变了决定？
  • 每个角色说出的设定都要带有他的立场和利益。
  • 斯皮尔不能只是解释者，他应当带着“数字永生失败”和“迁出执念”的危险性。
  • 卢恩不能只是科学家，他是吉姆现实侧最后的人类联系。

七、V2 工作流程

Pass 0：母本重置

状态：已完成。

当前 月球暗面_V2 章节文件来自 月球暗面_V1，用于重新开始。

Pass 1：最小清理

范围：

  • 统一人物名。
  • 修复明显错字、标点、重复口误。
  • 轻微拆分过长段落。

原则：

  • 第一、第二章只做最低限度。
  • 不改叙事结构。

Pass 2：章节卡

为第三至第七章建立章节卡，每章明确：

  • 本章要解决什么问题。
  • 谁在这一章发生变化。
  • 本章必须释放哪些信息。
  • 哪些信息必须推迟。
  • 哪些段落是作者原声，必须保护。

Pass 3：正文修订

按章节逐个修，不跨章大改。

建议顺序：

1. 第三章《月暗记录》：重构文明史信息释放。

2. 第四章《另一个世界》：重构游戏段落与主角团功能。

3. 第五章《半纪往事》：压实黑潮和旧时代证词。

4. 第六章《无尽的等待》：加强吉姆选择赴月的必然性。

5. 第七章《接近真相》：保留终点，补足赴月和死亡过程。

Pass 4：同步 HTML

每修完一章，同步生成：

  • Markdown 修订稿。
  • HTML 阅读稿。
  • 如有必要，更新索引和修订记录。

Pass 5：用户确认

每章修完后，由用户看 HTML；Codex 继续基于 Markdown 做下一轮局部修改。

八、后续协作的禁止项

  • 不把第一、第二章改成另一种文风。
  • 不把月暗体验解释得过早、过清楚。
  • 不把 V1 的口语感、犹豫感、梦境感全部磨平。
  • 不直接套用此前误改 V2 的内容。
  • 不为了显得“文学化”而删掉作者原本有生命力的笨拙、跳跃和自我怀疑。
  • 不在没有用户确认前，把七章结构拆成大量新章节。

九、下一步建议

下一步先做 Pass 1：最小清理，但只针对第三至第七章大范围处理；第一、第二章只做名字和明显错字级别的检查。

真正进入正文大修前，建议先为第三章《月暗记录》写一张详细章节卡，因为它承担了全书最大的信息压力，也是目前最容易从“小说”滑向“讲座”的地方。
