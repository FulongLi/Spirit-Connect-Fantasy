# 《月球暗面》V2 修订路线

整理日期：2026-06-06

## 一、V2 总目标

V2 的目标不是把 V1 全部推翻，而是让故事从“作者推动叙事”变成“人物性格、世界规则和伏笔共同推动叙事”。

核心方向：

> 让一切看起来像命中注定，而不是作者强行安排。

V2 应优先解决三类问题：

1. 地球文明史部分太泛泛，需要变成有重点、有证据链、有悬疑推进的发现过程。
2. 主角团进入《另一个世界》的游戏段不够有力量，需要变成三人关系和性格命运的根。
3. 吉姆登月和肉体死亡段偏草率，需要变成全书情感与主题的收束。

## 二、可以保留的部分

### 1. 月球暗面核心意象

石门、古战场、沙漠、稻田、时间切片、白视界、蓝黑球体、黑视界、时空井，这一串体验是 V1 最有辨识度的部分。

建议保留整体路线，但降低解释密度，让它更像一次无法完全理解的接触。

### 2. 三人组性格底色

吉姆：非必要介入者。  
安娜：读规则的人。  
查理：怕死但关键时刻不退的人。

这三个底色都很好，不需要重做，只需要让它们通过事件表现出来。

### 3. 艾拉的神秘感

小女孩/艾拉的设定非常有吸引力。她应保持温柔但高权限、亲近但不可完全信任的气质。

不要太早解释她的身份。她可以救吉姆，但每次救援都应带有代价或限制。

### 4. 数字吉姆线

数字吉姆不应是普通反派。他是吉姆的另一种可能：更冷静、更接近真相，也更危险。

这条线应保留，并在 V2 中更早埋下“他不是消失，而是在更深层等待”的感觉。

### 5. 结尾方向

吉姆为了救安娜、查理和其他人，选择真正抵达月球暗面。这是对的。

但执行上需要扩写，使它不只是一次任务，而是全书所有选择自然导向的终点。

## 三、需要重点提升的部分

### 1. 地球文明史不要写成报告

V1 的文明史段落信息很多，但太像会议陈述。V2 应改成“发现链”：

1. 吉姆只带回模糊片段。
2. 贾雷德从神话中找到对应结构。
3. 克罗斯教授和肖恩博士从数据中提出不同解释。
4. 灵接科技内部发现某些记录无法被系统伪造。
5. 结论不是一次性公布，而是逐步逼近。

重点不应是“把所有古文明都讲一遍”，而是选三到四个最有力量的文明案例，形成清楚对照。

建议保留的重点：

- 苏美尔：人类被改造/被放置的记忆。
- 华夏：魂魄、补天、女娲/伏羲作为系统修复和教化隐喻。
- 古埃及：Ka、Ba、Akh 对应意识层级。
- 玛雅：多次造人失败，对应实验迭代。

不要每个文明都平均展开。要让每一个例子承担不同功能。

### 2. 游戏段要变成三人组的根

《另一个世界》不是插曲，而应是三人组性格第一次被系统记录的地方。

V2 的游戏段应完成三件事：

1. 展示吉姆为什么会介入。
2. 展示安娜为什么会读规则。
3. 展示查理为什么怕死但不会退。

“挡下士兵那一下”可以保留并扩写，因为它是吉姆命运的预演：他总是在不需要他负责的地方伸手。

这段不应只是回忆游戏趣事，而应让读者明白：他们三个人之所以会一起走到月暗事故，不是偶然。

### 3. 登月段要变成命运收束

V1 后段有方向，但推进太快。V2 应把登月拆成三个层次：

1. 决定之前：吉姆知道代价，但还没有真正理解死亡。
2. 出发之前：他分别面对安娜、查理、卢恩博士、斯皮尔先生留下的情感压力。
3. 抵达之后：月球不是任务地点，而是他一生所有“非必要介入”的终点。

登月段的关键不是航天技术，而是：

> 吉姆终于进入一个没有人要求他负责、却只有他能负责的地方。

### 4. 视角需要规则

建议 V2 采用：

- 吉姆亲历与内心段：第一人称。
- 灵接科技、会议、斯皮尔、卢恩现实侧：第三人称。
- 作者序/前言：保留元叙事。

不要在同一小节里频繁切换“我”和“吉姆”。

### 5. 名字和术语统一

V2 已开始机械统一人物名：

- Jim Dickens → 吉姆·维尔 / James “Jim” Vale
- Charlie Filler → 查理·黑尔 / Charlie Hale
- 斯皮利康 → 斯皮尔
- 包教授 → 克罗斯教授
- 肖博士 → 肖恩博士
- 查尔斯·惠勒 → 亚瑟·惠勒

后续逐章精修时，还要统一：

- 数字校正 / 数字矫正
- 月暗 / 月球暗面
- 泰拉撒记录
- 主体核
- 非地球死亡区

## 四、建议的 V2 修改顺序

### 第一轮：结构与名字

目标：不大改正文，只完成 V2 基础。

- 建立 `月球暗面_V2`。
- 统一新版人物名。
- 生成 V2 修订路线。
- 重建 HTML 阅读版。

### 第二轮：前四章重排与重写

目标：让读者先认识三人组，再进入月暗。

建议顺序：

1. 作者序 / 前言压缩。
2. 新世纪与双生制度提前。
3. 第二次矫正事故强化。
4. 月暗之旅作为事故后的核心体验。

### 第三轮：重写游戏段

目标：让《另一个世界》成为三人组命运的根。

重点扩写：

- 第一次组队。
- 选择世界。
- 中世纪隐藏事件。
- 吉姆挡下士兵。
- 安娜记录规则。
- 查理嘴上怕死但跟上。

### 第四轮：重构文明史段

目标：从“会议讲解”改成“证据链发现”。

重点：

- 少讲总论，多写冲突。
- 贾雷德、克罗斯教授、肖恩博士应各自有不同角度。
- 吉姆不要像百科全书，他应该仍然困惑。

### 第五轮：重写登月与死亡

目标：让结尾成为全书自然结果。

重点：

- 吉姆的犹豫。
- 卢恩博士的阻止与最终陪伴。
- 斯皮尔的复杂立场。
- 安娜、查理的沉睡形成情感压力。
- 月球死亡不是“任务完成”，而是“命运抵达”。

## 五、V2 判断标准

一章改完后，用这几个问题检查：

1. 这一章是否由人物选择推动，而不是作者解释推动？
2. 是否有具体场景，而不是纯设定讲解？
3. 是否让吉姆、安娜、查理至少一人的性格更清楚？
4. 是否留下后续系列伏笔，但没有提前解释完？
5. 是否让读者感觉事情正在自然滑向月球，而不是突然转向登月？
