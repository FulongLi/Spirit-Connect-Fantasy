# Spirit Connect Project Collaboration Rules

Date: 2026-06-06

## 1. Document Language Rule

From this point onward, all newly generated project-level documents, setting files, chapter plans, character profiles, worldbuilding notes, and revision plans should be created in both Chinese and English by default.

Chinese documents are the primary creative and revision drafts.

English documents serve as external reference versions, cross-thread reuse material, and a base for future English-facing work.

Recommended naming:

- Chinese: `filename_CN.md`
- English: `filename_EN.md`
- Chinese HTML: `filename_CN.html`
- English HTML: `filename_EN.html`

If an older Chinese file already exists without a suffix, it may keep its original name. The English companion should use the `_EN` suffix.

## 2. Reading And Revision Rule

For future fiction revision:

- Codex should primarily read and edit Markdown files.
- The user should primarily read HTML files.
- Each major revision should preserve the previous version folder, such as `月球暗面_V1` and `月球暗面_V2`.

Markdown is the editing view. HTML is the reading view.

## 3. Worldbuilding Reference Rule

Whenever another thread is opened to continue writing *Moon's Dark Side*, *Fall of the Great Whales*, *Spirit Cat*, *The Well of Time*, *Where Souls Return*, or any side story, the series setting documents in this folder should be treated as the primary reference.

Current core setting documents:

- `灵接科技_系列设定.md`
- `灵接科技_系列设定_EN.md`

If a new thread cannot access the current conversation history, provide or point to these setting documents before continuing the writing work.

## 4. Setting Priority

If conflicts appear during later writing, use this priority order:

1. Settings explicitly updated by the user in the current conversation.
2. The latest series setting document.
3. The latest chapter revision draft.
4. The old V1 source text.
5. Scattered early conversation notes.

## 5. Writing Principle

Worldbuilding is not the final goal. Character fate is the spine of the series.

Each book should answer a worldbuilding question, but more importantly, each book should force one character into a defining choice:

- *Moon's Dark Side*: Jim decides whether to die on the Moon to save his friends.
- *Fall of the Great Whales*: Charlie learns that an ordinary person can still carry historical truth.
- *Spirit Cat*: Anna abandons the human-centered view of rules and learns non-human consciousness.
- *The Well of Time*: Digital Jim confronts whether he is only a copy.
- *Where Souls Return*: Everyone decides whether leaving Earth is truly freedom.
