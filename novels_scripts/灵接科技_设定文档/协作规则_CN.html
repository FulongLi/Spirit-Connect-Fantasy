《灵接科技》项目协作规则

整理日期：2026-06-06

一、文档语言规则

从本规则建立之后，凡是新生成的项目级文档、设定文档、章节规划、人物小传、世界观说明、修订方案，默认生成中文和英文两份。

中文文档作为主要创作稿和修订稿。

英文文档作为对外参考稿、跨对话复用稿、以及后续需要英文表达时的基础。

建议命名方式：

  • 中文：文件名_CN.md
  • 英文：文件名_EN.md
  • 中文 HTML：文件名_CN.html
  • 英文 HTML：文件名_EN.html

如果文档本身已经是中文旧文件，可以保留旧名，但新增英文版本时使用 _EN 后缀。

二、阅读与修订规则

后续小说正文修订时：

  • Codex 主要读取和修改 Markdown 文件。
  • 用户主要阅读 HTML 文件。
  • 每次较大版本修订，应保留旧版本文件夹，例如 月球暗面_V1、月球暗面_V2。

Markdown 是编辑视图，HTML 是阅读视图。

三、世界观参考规则

无论以后在哪个对话框继续写《月球暗面》《巨鲸陨落》《灵猫》《时间之井》《灵魂归处》或外传，都应优先参考本文件夹中的系列设定文档。

当前核心设定文档：

  • 灵接科技_系列设定.md
  • 灵接科技_系列设定_EN.md

如果新对话无法直接读取当前上下文，应先提供或指向该设定文档，再开始写作。

四、设定优先级

后续写作中，如出现冲突，优先级如下：

1. 用户在当前对话中明确更新的设定。

2. 最新版本的系列设定文档。

3. 最新版本的章节修订稿。

4. 旧版 V1 原文。

5. 早期聊天中的零散想法。

五、写作原则

设定不是目的，角色命运才是主线。

每一本书都要回答一个世界观问题，但更重要的是让一个角色完成一次命运选择：

  • 《月球暗面》：吉姆选择是否以死亡为代价去救朋友。
  • 《巨鲸陨落》：查理发现普通人也能承担历史真相。
  • 《灵猫》：安娜放弃人类规则中心视角，理解非人类意识。
  • 《时间之井》：数字吉姆面对自己是否只是复制品。
  • 《灵魂归处》：所有人决定是否真的离开地球。
