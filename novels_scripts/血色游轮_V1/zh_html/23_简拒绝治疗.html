23 简拒绝治疗

状态：框架种子

Main task

让简走向与斯皮尔、亚瑟都不同的道路。

Secondary task

留下“出口不在实验室里”的核心遗言。

POV limit

斯皮尔视角，私密场景，节奏放慢。

Required characters

简、斯皮尔，数字亚瑟可作为远处存在。

Required information

简拒绝上传，也拒绝把死亡交给机器处理。她认为斯皮尔会找到出口，但出口不在实验室里。

Forbidden mistakes

不要把简的拒绝写成放弃。她是在保留一种斯皮尔无法接受的尊严。

场景分段

  1. 简因疾病、创伤或实验后果需要治疗或上传选择。
  2. 斯皮尔试图说服她接受技术延续。
  3. 简拒绝，并留下对斯皮尔未来道路的预言或警告。

正文种子

斯皮尔说，我们可以保留你。

简听见这句话，笑了一下。她说，伊莱亚斯，保留不是活着。

很久之后，斯皮尔仍然记得她那天的声音：你会找到出口，但出口不在实验室里。
